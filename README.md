# Лабораторная работа 6 (Вариант 10)

## Условие задачи
Определить, принадлежит ли точка с координатами (x, y) заштрихованной области, ограниченной двумя прямыми. Использовать условный оператор if-else и логические операции.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить переменные `x` и `y` типа `double` для хранения координат точки.
3. Запросить у пользователя ввод координат (x и y).
4. Считать введенные значения с клавиатуры в переменные `x` и `y`.
5. Проверить первое условие (нахождение под правой верхней границей): `y <= x + 2`.
   - Если условие ложно (Нет), перейти к шагу 12.
6. Проверить второе условие (нахождение под левой верхней границей): `y <= -x + 8`.
   - Если условие ложно (Нет), перейти к шагу 12.
7. Проверить третье условие (нахождение над правой нижней границей): `y >= x - 2`.
   - Если условие ложно (Нет), перейти к шагу 12.
8. Проверить четвертое условие (нахождение над левой нижней границей): `y >= -x + 4`.
   - Если условие ложно (Нет), перейти к шагу 12.
9. Если все 4 условия истинны (Да), значит, точка находится внутри ромба. Теперь проверяем, лежит ли она ровно на одной из границ:
   - Если `y == x + 2` **ИЛИ** `y == -x + 8` **ИЛИ** `y == x - 2` **ИЛИ** `y == -x + 4`:
     - Вывести сообщение: «Точка находится на границе области».
   - Иначе (не на границе):
     - Вывести сообщение: «Точка принадлежит области».
   - Перейти к шагу 13.
10. (Шаг 12 из предыдущих пунктов): Вывести сообщение: «Точка не принадлежит области».
11. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    double x, y;

    printf("Введите координаты точки (x y): ");
    scanf("%lf %lf", &x, &y);

    if ((y <= x + 2) && (y <= -x + 8) && (y >= x - 2) && (y >= -x + 4))
    {
        if ((y <= x + 2) && (y <= -x + 8) && (y >= x - 2) && (y >= -x + 4))
        {
            printf("Точка (%.2lf, %.2lf) находится на границе области\n", x, y);
        }
        else
        {
            printf("Точка (%.2lf, %.2lf) принадлежит области\n", x, y);
        }
    }
    else
    {
        printf("Точка (%.2lf, %.2lf) не принадлежит области\n", x, y);
    }

    return 0;
}
```
