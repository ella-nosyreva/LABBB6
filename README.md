# Лабораторная работа 6 (Вариант 10)

## Условие задачи
Определить, принадлежит ли точка с координатами (x, y) заштрихованной области, ограниченной двумя прямыми. Использовать условный оператор if-else и логические операции.

## 1. Контрольные примеры (до запуска программы)
По рисунку варианта я выбрал три точки:
1. Точка внутри области: (x, y) = (3, 3) → принадлежит области
2. Точка вне области: (x, y) = (0, 0) → не принадлежит области
3. Точка на границе области: (x, y) = (3, 5) → находится на границе области
